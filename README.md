# Hotkey Inspector

Локальная macOS-утилита на SwiftUI. Источники сочетаний — меню выбранного приложения через Accessibility и сохранённые системные назначения macOS. Готовые стандартные комбинации не подставляются; справочные названия используются только для известных системных ID.

## Запуск

Откройте `HotkeyInspector/HotkeyInspector.xcodeproj` в Xcode, выберите схему HotkeyInspector и My Mac, нажмите ⌘R. Требуются macOS 27 и Xcode 27 (текущие настройки проекта).

Сборка из терминала в постоянный локальный каталог:

```sh
xcodebuild -project HotkeyInspector/HotkeyInspector.xcodeproj \
  -scheme HotkeyInspector -configuration Debug -destination 'platform=macOS' \
  -derivedDataPath "$HOME/Library/Developer/Xcode/DerivedData/HotkeyInspectorLocal" build
open "$HOME/Library/Developer/Xcode/DerivedData/HotkeyInspectorLocal/Build/Products/Debug/HotkeyInspector.app"
```

Каталог сборки находится вне Documents: файловый провайдер может добавлять к `.app` атрибуты FinderInfo и ломать codesign с ошибкой `resource fork, Finder information, or similar detritus not allowed`.

App Sandbox отключён: межпроцессный Accessibility несовместим с ним. Bundle identifier сохранён от исходного проекта. Разрешения выдаются конкретной сборке приложения; после смены пути или подписи macOS может потребовать повторного разрешения. Для локальной отладки используйте один путь сборки.

## Возможности

- Имя активного приложения и автоматически обновляемый список обычных приложений.
- Выбор цели закреплён: нажатие на Inspector не подменяет её самим Inspector. «Последнее активное» выбирает последнее внешнее приложение.
- Запрос и проверка Accessibility, переход в системные настройки. Без доступа чтение блокируется.
- Чтение вложенного меню без выполнения команд. Таблица показывает сочетание, действие с путём меню и доступность; приложение указано в выборе источника над таблицей. Его название сохраняется в копируемых строках.
- Поиск по действию, пути, приложению и сочетанию; фильтры доступности и потенциальных конфликтов.
- ⌘F переводит фокус в поиск выбранной вкладки («Меню» или «Система»). ⌘R обновляет её данные; для меню нужны Accessibility-доступ, выбранное приложение и отсутствие текущего чтения. Escape отменяет текущее чтение только во вкладке меню. На вкладке «Монитор» эти команды недоступны. Команды также находятся в меню «Правка» (поиск) и «Вид» (обновление/отмена); системные назначения могут перехватывать сочетания до приложения.
- В таблице меню можно выбирать строки, в том числе несколько с Command/Shift, и копировать через ⌘C, «Правка → Копировать» или контекстное меню «Копировать строки». Копируются только выбранные видимые строки в порядке таблицы: сочетание, действие, путь меню, приложение, статус. Столбцы разделены табуляцией, строки — переносом; управляющие символы внутри полей заменяются пробелами. При фильтрации и обновлении исчезнувшие строки удаляются из выбора.
- Совпадения физических клавиш и модификаторов у доступных команд одного приложения помечаются как потенциальные конфликты. Они не доказывают конфликт исполнения: контекст команд может различаться. При отсутствии физического кода сравнение пропускается. Сочетания разных приложений не объявляются конфликтами.
- Переключатель «Поверх окон» находится в toolbar (булавка) и меню «Вид»; сохраняется между запусками. Заголовок внутри содержимого убран, строка «В фокусе macOS» сохранена. Вкладки «Меню», «Система» и «Монитор» используют нативный стиль `.tabBarOnly` в toolbar; короткие подписи оставляют место для поиска в компактном окне. Окружающая рамка и вложенные отступы убраны.
- В меню и системных назначениях используется системный поиск SwiftUI в toolbar со штатной очисткой. Запросы независимы и сохраняются при переключении вкладок; фильтры расположены над результатами. На вкладке «Монитор» поля поиска нет. Один общий `NavigationStack` и один `.searchable` обслуживают окно; состояние запросов и фильтров хранится вне условного представления поиска.
- При сужении окна группа выбора приложения и группы действий переходят в вертикальное расположение. Основной области таблицы выделено не менее 180 pt по высоте; длинные инструкции и раскрытые ограничения прокручиваются отдельно. Ограничение размера содержимого — 700×560 pt; системная панель окна может увеличить фактический минимум. Краткое указание источника остаётся видимым, подробности доступны через «Источник и ограничения».
- Вкладка «Система»: сохранённые системные сочетания, состояние включения, поиск по действию/сочетанию/ID, фильтр включённых записей и ручное обновление. Не требует Accessibility-доступа.
- На вкладке «Монитор» допустимые сочетания и хранение только в памяти указаны постоянно. Подробности фильтрации, защищённого ввода и источника данных доступны через «Источник и ограничения»; предупреждение о том, что нажатие не доказывает выполнение команды, остаётся видимым.

## Системные сочетания

Вкладка «Система» читает только `~/Library/Preferences/com.apple.symbolichotkeys.plist`, словарь `AppleSymbolicHotKeys`. Каждая комбинация берётся из сохранённой записи `value.parameters`, состояние — из `enabled`. Например, пользовательское назначение Spotlight ⌘F отображается как ⌘F, независимо от привычного стандартного сочетания. Данные загружаются при появлении вкладки и по кнопке «Обновить». Кнопка «Настройки клавиатуры» открывает раздел macOS; приложение само ничего в нём не меняет.

Это снимок сохранённой конфигурации, а не полный каталог всех работающих системных сочетаний. Отсутствие файла или нужного словаря показывается как ошибка чтения. Пустой словарь остаётся пустым: стандартные комбинации не добавляются. Файл может не содержать все назначения и может обновляться с задержкой после изменений настроек. Сочетания Services, VoiceOver, медиа-клавиши, глобальные регистрации сторонних приложений и другие системные обработчики не гарантированно охвачены.

Формат файла и соответствие ID действиям не являются публичным контрактом Apple. Небольшая таблица названий служит справкой, не содержит комбинаций и не определяет включение. Неизвестные команды показаны как «Системная команда #ID». ID виден у каждой строки для сверки с настройками. Записи без назначения или с неподдерживаемым форматом остаются в таблице как «Нет данных»; это не значит «выключено». Статус «Включено» не доказывает выполнение команды.

Публичный Carbon API `CopySymbolicHotKeys` описывает системные сочетания, но, согласно `CarbonEvents.h` в SDK, не позволяет определить действие конкретной записи. В этой версии используется файл сохранённых назначений с ID; его данные не выдаются за результат проверки регистрации или исполнения.

Системные модификаторы трактуются как `CGEventFlags`, а не AX-маски: нулевое значение не добавляет Command. Fn, Caps Lock, цифровой блок и неизвестные дополнительные флаги сохраняются в представлении. Отсутствующий код `65535` не превращается в клавишу. Системные строки не участвуют в текущем поиске конфликтов между командами меню одного PID.

## Переназначения и полнота данных

AX читает фактические атрибуты меню, включая переназначения, которые приложение уже отразило в них. После изменений сочетаний перечитайте меню; некоторые приложения требуют перезапуска. Отдельный разбор `NSUserKeyEquivalents` не реализован: записи настроек сами по себе не доказывают, что приложение их применило.

Снимок загружается при выборе приложения, получении разрешения и нажатии «Обновить меню». Изменения документа сами по себе не запускают повторное чтение. Откройте нужный документ/меню в целевом приложении и повторите чтение. Лениво создаваемые пункты, контекстные меню, внутренние обработчики клавиш, глобальные и системные сочетания могут отсутствовать. Нулевой результат не означает отсутствия сочетаний.

Обход ограничен 8 секундами, 4000 элементами и 25 уровнями, каждый AX-запрос имеет таймаут 150 мс. Время может немного превысить лимит на последний запрос. Неполный обход показывается с предупреждением. Переключение цели или отмена не позволяет старому результату заменить новый.

## «Монитор» и приватность

Монитор выключен при запуске. На вкладке «Монитор» пользователь явно нажимает «Запустить» и при необходимости предоставляет разрешение «Мониторинг ввода» в настройках macOS.

- Используется пассивный `CGEventTap` (`listenOnly`): события не меняются и не блокируются.
- До создания записи пропускаются только сочетания с Command или Control и физические F1–F20. Shift, Option, Fn и Caps Lock сами по себе не разрешают запись обычных клавиш. Автоповторы исключены.
- Unicode-текст события и содержимое полей не читаются. Имя клавиши определяется из кода и текущей раскладки. Отображается также физический код.
- При защищённом вводе события пропускаются. Отзыв разрешения останавливает монитор; отключение tap системой требует ручного повторного запуска.
- До 100 событий хранятся только в памяти. Нет файла журнала, экспорта, аналитики или сетевой отправки. «Очистить» удаляет историю; закрытие окна останавливает монитор и очищает её.
- Нажатие и приложение в фокусе не подтверждают выполнение команды. Медиа-клавиши и перехваченные системой события могут не поступать.

## Проверки

```sh
sh Tests/run.sh
```

Проверяется разбор AX-модификаторов (Command подразумевается), код клавиши 0, отсутствующие атрибуты, Space, функциональные глифы, фильтрация всех кодов 0–127 под текстовыми модификаторами, автоповторы и семантика потенциальных конфликтов. Синтетические plist-проверки покрывают системные переназначения, выключенные и неизвестные записи, Fn, отсутствие назначения, недопустимые параметры, поиск и фильтрацию. Проверки копирования строк покрывают пустой выбор, устаревшие и скрытые ID, порядок строк, статусы и управляющие символы внутри полей. Всего 949 проверок.

Проверка системных сочетаний (разрешения Accessibility и мониторинга ввода не нужны):

1. Перезапустить собранное приложение и открыть «Система»: должна появиться таблица ваших сохранённых назначений.
2. Найти Spotlight. Сверить сочетание и состояние с «Системные настройки → Клавиатура → Сочетания клавиш → Spotlight».
3. Проверить поиск по ID, поиск по сочетанию и фильтр «Только включённые».
4. При самостоятельном изменении назначения в настройках нажать «Обновить» после сохранения macOS. Приложение должно показать новое сочетание; если оно ещё не сохранено в файл, повторить обновление позднее.
5. Проверить, что включённая запись без `value` остаётся «Включено» / «Нет данных» и что «Монитор» остаётся выключенным.

Ручная проверка после выдачи разрешений:

1. Выбрать Finder → «Обновить меню». Сверить несколько сочетаний с его меню.
2. Прочитать меню Zed; при пустом результате попробовать TextEdit. Не все приложения предоставляют одинаковый набор AX-атрибутов.
3. Проверить поиск и оба фильтра. Отменить чтение и сменить цель во время чтения.
4. Изменить пользовательское сочетание через настройки macOS, дождаться его применения приложением и повторить чтение.
5. Включить монитор, набрать обычный текст в отдельном тестовом документе (не пароль): история не должна пополниться. Нажать ⌘A и F-клавишу, проверить записи. Остановить монитор и проверить, что новые записи не появляются.
6. Проверить отзыв разрешений, безопасное закрытие окна и работу «Поверх окон».

Проверка выбора и копирования в таблице меню после получения Accessibility-доступа:

- Выбрать строку, перемещаться стрелками, выбрать несколько строк с Command/Shift. Проверить ⌘C при фокусе таблицы и пункт копирования в меню «Правка»; вставить результат в тестовый документ.
- Вызвать «Копировать строки» правым кликом на выбранных строках, затем на другой строке. Убедиться, что копирование относится к строкам, на которых открыто меню; на пустой области команда не показывается.
- Скрыть выбранную строку поиском/фильтром: она не должна попасть в копирование или восстановить выделение после сброса фильтра. Обновить меню и сменить целевое приложение: старый выбор не должен переноситься на новый снимок.
- Выделить текст в поле поиска и нажать ⌘C: должен копироваться текст поля, а не строки таблицы.

Проверка клавиатурных команд:

- Во вкладках меню и системных назначений нажать ⌘F из другого элемента: фокус должен перейти в соответствующий поиск без изменения запроса или вкладки.
- На «Системных» нажать ⌘R: время снимка должно обновиться, запрос поиска и фильтр — сохраниться. Команды должны работать также через меню «Правка» и «Вид».
- На вкладке «Монитор» поиск, обновление и отмена должны быть недоступны; их вызов не запускает монитор и не очищает историю. Без Accessibility-доступа обновление меню и отмена также недоступны.
- После выдачи доступа запустить чтение меню: ⌘R во время чтения недоступно, Escape отменяет чтение. Без текущего чтения Escape не должен очищать таблицу или историю.

Проверка системного поиска:

- В меню и системных назначениях вызвать ⌘F, ввести запрос, очистить штатной кнопкой поля. Во вкладке «Система» проверить запрос `Spotlight`, ID `64`, сочетание `⌘F` и запрос без совпадений.
- Совместить поиск с checkbox-фильтрами: очистка запроса не сбрасывает фильтры. Переключиться между вкладками, включая «Монитор»: запросы и фильтры должны сохраниться, поле поиска на мониторе — отсутствовать.
- Проверить поле и ⌘F в компактном и широком окне, повторить переключение вкладок при активном поиске. Системный поиск не должен исчезать при сужении окна или вызывать сбой toolbar.

Проверка изменения размера окна:

- Сузить окно на каждой вкладке: кнопки и фильтры должны оставаться доступными, таблица — прокручиваться самостоятельно, без общей прокрутки всего экрана.
- Раскрыть диагностику Accessibility и «Источник и ограничения». При нехватке места прокручиваются эти области; основная область результатов не исчезает.
- Ввести запрос поиска и менять ширину окна через порог адаптивного layout: запрос и фокус должны сохраниться. Проверить также сохранение выбранных строк в таблице меню после выдачи Accessibility-доступа.

## Как устроен код

- `Hotkey.swift`: значения приложения, сочетания и команды; `OptionSet` для флагов; чистая логика конфликтов и безопасного фильтра.
- `SystemHotkey.swift`: значения системной настройки и снимка, чтение plist только на чтение, проверка типов и параметров, отображение реальных модификаторов, справочные названия ID, поиск.
- `SystemHotkeysView.swift`: самостоятельная вкладка с `@State` для снимка и ошибки, `@Binding` для запроса и фильтра. SwiftUI перерисовывает таблицу при изменении этих значений; общий AX-модельный слой для чтения небольшого локального plist не нужен.
- `MenuReader.swift`: обход только ветки AXMenuBar, таймауты, ограничения и ошибки. Объекты AX остаются в задаче чтения.
- `InspectorModel.swift`: `@MainActor ObservableObject` хранит состояние интерфейса. `@Published` уведомляет SwiftUI об изменениях. `Task.detached` читает меню вне главного потока; `await` ожидает результат без блокировки окна. Идентификатор поколения защищает от устаревших результатов.
- `HotkeyMonitor.swift`: жизненный цикл event tap, фильтрация и ограниченная история. Callback подключён к главному run loop; `MainActor.assumeIsolated` опирается именно на эту гарантию.
- `InspectorStyle.swift`: единые заголовки, типографика сочетаний, адаптивная строка снимка и раскрываемый блок источника. Используются системные размеры шрифта и семантические цвета; подробности не зависят от кастомных карточек.
- `ContentView.swift`, `AccessibilityPermissionView.swift`, `MonitorView.swift`: представления. `@StateObject` владеет моделями, `@ObservedObject` даёт дочернему представлению наблюдать уже созданную модель, `@AppStorage` сохраняет только настройку положения окна.

Учебные примеры заменены фактическими данными. Для следующего учебного разбора удобно начать с `ShortcutModifiers.accessibility`, затем разобрать `guard`, Optional и обработку ошибок в `MenuReader`.

## Если разрешение включено, но меню не появляется

Статус внутри приложения основан на AXIsProcessTrusted для запущенного процесса. Переключатель в настройках может относиться к другой локальной сборке: подпись Sign to Run Locally привязана к хешу кода. Закройте приложение, запустите текущую сборку по пути выше, выключите/включите разрешение именно для неё и перезапустите. Если не помогло, удалите старую запись HotkeyInspector в настройках и добавьте текущую .app через «+». В блоке «Доступ включён, но меню не загружается?» доступны путь запущенной копии и «Показать приложение в Finder». Настройки не меняются программно. При получении доступа статус обновляется автоматически, выбранное меню читается. Для начала выберите Finder; после чтения видно количество найденных сочетаний; число проверенных AX-элементов доступно в «Источник и ограничения».
